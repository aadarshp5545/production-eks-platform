01

Production-Style AWS EKS DevOps Platform

Designed and deployed a production-style AWS Kubernetes platform using Infrastructure as Code and automated CI/CD. The platform provisions the complete infrastructure with modular Terraform, including networking, security groups, IAM, EKS, managed node groups, ECR and an Application Load Balancer.

Containerized applications are built through CI/CD, published to Amazon ECR and deployed to Kubernetes running on Amazon EKS. Application traffic is exposed through an AWS Application Load Balancer and routed to Kubernetes workloads using the AWS Load Balancer Controller and TargetGroupBinding.

The infrastructure state is maintained remotely in Amazon S3, while GitHub Actions provides controlled infrastructure planning and application deployment workflows.
